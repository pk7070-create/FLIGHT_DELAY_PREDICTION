# ✈️ Flight Delay Prediction

A Machine Learning based web application that predicts whether a flight will be delayed or on time using Logistic Regression.

# 📌 Project Overview

This project builds a binary classification model to predict flight departure delays.

The workflow includes:

Data Cleaning

Feature Engineering

One Hot Encoding

Train-Test Split

Logistic Regression Model Training

Model Evaluation (Accuracy & Confusion Matrix)

Streamlit Web App Deployment

# 🧠 Machine Learning Model

Algorithm: Logistic Regression

Type: Binary Classification

Target Variable: DELAYED

1 → Flight Delayed

0 → Flight On Time

# 📊 Features Used

Some key features:

MONTH

DAY_OF_WEEK

DISTANCE

SCHEDULED_DEPARTURE

AIRLINE (One Hot Encoded)

DESTINATION_AIRPORT (One Hot Encoded)

# 🚀 Streamlit Web App

The model is deployed using Streamlit where users can:

Select flight details

Choose airline

Choose destination airport

Get real-time delay prediction
